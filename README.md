# Browse — умный браузер

Browse — концепт браузера с AI-помощником, который помогает исследовать веб, понимать страницы и выполнять повторяющиеся действия.

## Цель

Сделать браузер, где нейросеть работает рядом с веб-страницей, а не заменяет пользователя. Помощник должен уметь объяснить содержимое страницы, выделить главное, сравнить источники и подготовить следующий шаг, оставляя пользователю контроль перед любым действием.

## MVP

- вкладки и адресная строка;
- AI-панель для текущей страницы;
- краткое содержание и ответы по содержимому открытой страницы;
- извлечение задач, ссылок и ключевых фактов;
- история AI-запросов по вкладке;
- подтверждение пользователя перед отправкой форм, публикацией или другими внешними действиями;
- локальный режим с подключением к Ollama и возможность использовать внешний AI API.

## Архитектура

```text
Browser shell
  ├─ Tab manager
  ├─ Navigation / address bar
  ├─ Page context extractor
  ├─ AI assistant panel
  ├─ Action planner + confirmation gate
  └─ Provider adapters (Ollama / API)
```

Контекст страницы должен передаваться модели только по явному запросу пользователя. Команды, которые могут изменить данные на сайте, проходят через отдельный экран подтверждения.

## План реализации

1. Собрать desktop-shell и вкладки.
2. Добавить извлечение текста текущей страницы.
3. Подключить AI-провайдер и потоковый ответ.
4. Реализовать суммаризацию, вопросы к странице и сравнение источников.
5. Добавить безопасный планировщик действий с подтверждением.
6. Описать демо-сценарий и добавить скриншоты.
